Materializr, en tu equipo.

Modelado paramétrico de sólidos con OpenCascade y un solver de restricciones de croquis. El proyecto de origen distribuye actualmente aplicaciones nativas para escritorio y móviles.

Materializr no ofrece una compilación web soportada. Este sitio estático no puede ejecutar su interfaz nativa. Esta página no ejecuta Materializr en el navegador.

Obtener la aplicación oficial → Código fuente e instrucciones de compilación →

Usar tu propio servidor

El acceso desde navegador necesita un servidor independiente que ejecute Materializr con un escritorio remoto protegido. Cuando ese servicio esté desplegado, se puede conectar su dirección HTTPS a esta página.
